# Pricing — PlotTheChart

## Free Tier
- Price: $0/month
- Limits: 5 Saved Projects, Standard Chart Types (Bar, Line, Pie)
- Features: Anonymous charting, basic data entry, standard export options (PNG/SVG)

## Pro Tier
- Price: $12/month (billed annually) | $15/month (billed monthly)
- Limits: Unlimited Saved Projects, All Chart Types (including Radar, Scatter, Treemap)
- Features: Cloud syncing, advanced configuration options, custom branding, high-res exports

## Enterprise Tier
- Price: Custom — contact sales@plotthechart.com
- Limits: Unlimited everything
- Features: Team workspaces, API access, SSO integration, priority support, custom chart types
